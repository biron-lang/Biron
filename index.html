Biron

A statically typed systems programming language designed for robust applications.

Download Documentation GitHub ›

Biron blends structural and nominal typing with a focus on ergonomics and expressivity, compiling to native executables or portable C.

The centerpiece is the lexically scoped effect system. Everything with external consequence is threaded through effects, so all Biron code is hermetic by default, which means an entire program can be sandboxed, introspected, and intercepted from a single place. 

import core.io;
import core.system;
fn main() <System> {
  with IO = System!.console;
  io::print("Hello, world!\n");
}

Hello, world

import pulls in the io and system core modules. Each one defines an effect, IO and System respectively.

main is given a System effect implicitly: a set of implementations of these interfaces for the host system. One of them, console, implements the IO effect.

with establishes that IO effect from System!.console, so print, which depends on IO, has an implementation to run against.
